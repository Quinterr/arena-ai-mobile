# Arena Mobile

Нативное мобильное приложение (iOS / Android), которое переносит [arena.ai](https://arena.ai) на телефон **без браузера и без WebView**. Ни одного `<WebView>`, ни одного iframe — весь интерфейс собран из нативных вью через React Native + Expo. Тот же код запускается в вебе (react-native-web) — это удобно для превью.

## Что внутри

Пять вкладок, повторяющих продукт arena.ai и адаптированных под палец:

| Вкладка | Что делает |
| --- | --- |
| **Chat** | Экран «Experience the frontier»: выбор модели, стартовые сценарии (лендинг, дашборд, игра, design-to-code), композер, история диалогов |
| **Battle** | Battle Mode: две анонимные модели отвечают на один промпт, вы судите, потом раскрытие имён |
| **Ranks** | Лидерборды Text / Agent / WebDev / Image / Vision: поиск, фильтры, зачёт лабораторий, спарклайны, карточка модели |
| **Pulse** | Лента изменений: модель дня, ваш вотчлист, крупнейшие движения, свежие релизы, зачёт лабораторий |
| **You** | Личный рейтинг из ваших голосов, совпадение с толпой, поиск по истории, настройки |

## Фишки, которых нет на сайте

1. **Свайп-голосование в батле.** Свайп карточки вправо — победа, влево — отказ, с тактильной отдачей (`expo-haptics`). Кнопки A / B / Ничья / Обе плохи тоже на месте.
2. **Личный Elo и «твой вкус».** Каждый ваш голос пересчитывает персональный рейтинг моделей (`src/lib/elo.ts`). Со временем получается ваш собственный лидерборд — часто он не совпадает с глобальным.
3. **Crowd agreement.** Процент совпадения ваших голосов с глобальным рейтингом: видно, вы мейнстрим или контрарианец.
4. **Offline-first.** Снимок лидербордов зашит в приложение, история и голоса лежат в `AsyncStorage`. Всё работает в самолёте; в шапке видно, что это офлайн-копия и когда была синхронизация.
5. **Dual answer.** Один промпт уходит сразу двум моделям, ответы стримятся параллельно в одном треде — сравнение прямо в чате, без ручного копипаста.
6. **Compare + калькулятор стоимости.** Радар-чарт по пяти осям (Quality / Agentic / Speed / Value / Reliability), таблица «голова к голове» и слайдер «запросов в день», который считает счёт за месяц по реальным ценам за токены.
7. **Watchlist и Pulse.** Звёздочка на модели (или long-press по строке лидерборда) — и её движения попадают в ленту Pulse вместе с «моделью дня» и стриком посещений.
8. **Русский и английский интерфейс** + светлая / тёмная / системная тема, переключаются мгновенно (`src/i18n.ts`).
9. **Ответы генерируются на устройстве.** Демо не требует ключей и сети: движок персон в `src/lib/responder.ts` даёт разным лабораториям разный голос, структуру и длину ответа, плюс имитацию стриминга со скоростью, пропорциональной реальной.
10. **Нативные мелочи:** шаринг результата батла и карточки модели через системный share sheet, pull-to-refresh, haptics, tabular-nums для цифр, спарклайны на `react-native-svg` без единой картинки.

## Данные

Каталог моделей в `src/data/models.ts` — снимок публичных лидербордов Arena: **Text Arena (2 сентября 2026)** и **Agent Arena (5 сентября 2026)**: Elo и доверительные интервалы, число голосов и сессий, net improvement, confirmed success, steerability, tool hallucination, цены за миллион токенов, контекст и лицензии.

Чтобы подключить живой бэкенд, достаточно заменить два места:

- `src/data/models.ts` → загрузка каталога и рейтингов;
- `synthesize()` / `stream()` в `src/lib/responder.ts` → реальный стриминг ответов (SSE / fetch).

Остальной код на источник данных не завязан.

## Запуск

```bash
npm install

# на телефоне: запустить и отсканировать QR из Expo Go
npm start

npm run ios       # симулятор iOS (нужен macOS)
npm run android   # эмулятор/устройство Android
npm run web       # тот же код в браузере (для превью)
```

Проверки:

```bash
npm run typecheck   # tsc --noEmit
npm run smoke       # рендер всех экранов в jsdom, ловит рантайм-ошибки без браузера
```

Сборка нативных бинарников — через EAS: `npx eas build -p ios` / `-p android` (bundle id `ai.arena.mobile`).

## Структура

```
app/                     маршруты expo-router (file-based routing)
  _layout.tsx            провайдеры + телефонная рамка для веб-превью
  (tabs)/                chat · battle · leaderboard · pulse · you
  chat/[id].tsx          диалог со стримингом и dual-режимом
  model/[id].tsx         карточка модели (модальный экран)
  compare.tsx            сравнение двух моделей + калькулятор цены
src/
  components/            Icon (свой SVG-сет), ui-кит, Markdown, ModelPicker
  data/                  каталог моделей, промпты и подсказки
  lib/                   elo, форматирование, генератор ответов
  store/app.tsx          состояние + персист в AsyncStorage
  theme.ts, i18n.ts      палитра и переводы
tools/smoke.mjs          headless-проверка всех экранов
```

## Стек

Expo SDK 57 · React Native 0.86 · expo-router · TypeScript (strict) · react-native-svg · AsyncStorage · expo-haptics. Никаких UI-библиотек — весь интерфейс и все иконки написаны руками.

---

Это независимый клиент-демо, не аффилированный с Arena. Ответы моделей в приложении синтезируются локально и не являются реальными выводами перечисленных моделей.
